# Booked demo

An original, playful booking prototype. Make time for good things.

Try the product story, open the fictional workspace, create a booking link, and explore booking, unavailable times, alternative suggestions, counterproposals, host acceptance/decline, rescheduling, cancellation, and invitation boundaries.

This static demo uses browser-local storage. All calendars and free/busy data are fictional. Booking links and their expiry/use rules do not sync across people or devices and are not production enforcement. Share the homepage so each friend can try their own fictional workspace. Use fictional names and example.test email addresses only.

Host availability is a UTC recurring schedule with notice, horizon, meeting-gap and date-override controls. Guest times can be displayed in selected IANA timezones. Real calendars, OAuth, accounts, emails, reminders, payments and team scheduling are not connected. This is not full Calendly parity.

Original Booked artwork and copy. Includes keyboard navigation, restrained animation and reduced-motion support. No external fonts, tracking, credentials or remote API are required. To reset fictional activity, clear this site's browser storage.

The Pages workflow publishes this static demo only. The product name Booked.com does not imply ownership of a custom domain.
